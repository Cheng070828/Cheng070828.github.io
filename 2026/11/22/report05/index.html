MySQL

安装教程

1.官网地址 https://dev.mysql.com/downloads/mysql/

2.安装完成后熟悉语法
show databases； 查看数据库
create database; 数据库名 ； 创建一个数据库
drop database 数据库名； 删除一个数据库
use 数据库名； 选择数据库
show tables; 查看存在的全部数据表
desc 数据表名;
insert into table_one(name,sex,age,love) values (“lc”,“男”,“18”,“篮球”); 插入数据
select * from table_one; 查看数据表内容 (为查询全部，或可以查询单个字段 将改为name 等) 注:此末位可加 where name或其他字段 like “l_” 来指定查询的内容包括l的两位,(_改为%则为查询全部) {本质通过where添加条件查询}
alter table 表名 drop 字段名; 删除指定字段
truncate table 表名; 清空数据表
delete from 表名 where 字段名=字段值;
alter table_one modify age varchar(10); 修改字段类型
alter table table_one tel int; 添加字段名
alter table table_one change tel phone int; 修改字段名
